# Ale

> [!IMPORTANT]
> This project is archived and no longer maintained. It is kept public for
> historical reference. Ale targets Python 2.7 and legacy versions of macOS and
> is not expected to run on modern systems.

Smart command line launcher for OS X.

## Examples

You can search in Google, Amazon, Google Maps, Youtube, Yahoo, Wolfram etc. from ale:

     ale> google apple
     ale> amazon book
     ale> youtube eminem
     
You can open applications from ale:

    ale> App Store
    ale> Mail
    
You can open Gmail, Twitter, Google Drive from ale:

    ale> gmail
    ale> twitter
    
You can also empty trash, remove files, restart computer etc.:
    
    ale> emptytrash
    ale> remove document
    ale> restart
